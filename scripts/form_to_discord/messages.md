# NGK2027S 申込自動処理 文面集

Googleフォームの回答をスタッフ専用チャンネルへ投稿し、申込者へ受付メールを送る。
その投稿が承認されたら、承認メールと一般向けチャンネルへの投稿を送り、ロールを付ける。

実際に送られるのは次の2つ。このファイルは両方を読みやすく並べたもの。

| 種類 | どこにあるか |
|---|---|
| メール | `Messages.gs` |
| Discord 投稿 | `../discord_sync/src/messages.py` |

文面を直したら、このファイルと上のどちらかの両方に反映する。

承認メールに出る Discord の招待リンクは、Apps Script のスクリプトプロパティ
`DISCORD_INVITE_URL` から入る。リンクそのものはこのファイルにもコードにも書かない。

文面は NGK2026S で実際に送ったものに合わせてある。

# Discord スタッフ専用チャンネルへの投稿

申し込みが届いたときに投稿する。埋め込み形式で、空欄の項目は出さない。

承認の決まりの説明は、埋め込みの最後の項目「この後の流れ」に出す。
埋め込みの上に出すと、何の申し込みかより先に手順が目に入る。
一番下 (footer) にも置けない。そこではカスタム絵文字が画像にならず、`:yosasou:` の文字のまま出る。
投稿の日時は Discord が footer の横に自動で出す。

1項目は1024字、埋め込み全体では6000字までしか載せられない。
超えると投稿そのものが断られるので、収まるところで値を切り、
`…(以下略。スプレッドシートを見てください)` を付ける。
それでも入りきらない項目は、末尾に次の1項目でまとめて知らせる。

```
表示できなかった項目     3件。スプレッドシートを見てください
```

`{{コミュニティ名}}` と `{{参加形態}}` は申込者が書いた文字なので、100字で切り、
太字やリンクとして描かれないよう記号を打ち消してから差し込む。
この投稿は一般向けチャンネルに出るため、書いたとおりの飾りが付くと実行委員会からの案内に見える。

`{{お願いする作業}}` の差し替え

画像を用意してもらうかは、ロゴかスライドを希望していて、かつ

# Discord スタッフ専用チャンネルへの投稿 (うまくいかなかったとき)

## D6 Discordユーザーが見つからないとき

送信条件 採択メールを送ったあと、入力されたDiscordユーザー名のメンバーがサーバーに居ないとき。
このとき D4・D5 の投稿とロール付与は行わない。採択メールは送る。

採択メールで初めて招待リンクを送るので、この時点で未参加なのはふつうのこと。
申込者が参加すれば次の回に自動で続きを行う。同じ知らせを繰り返さないよう、
1件につき1回だけ投稿し、「ユーザー未特定通知」列に時刻を書く。

```
⚠️ Discordユーザーが見つかりません

受付番号                 {{受付番号}}
入力されたユーザー名     {{Discordユーザー名}}
付けるはずだったロール   {{ロール名}}
元の申し込み投稿         {{元投稿リンク}}

採択メールは送信済みです。申込者がサーバーに参加すれば自動で続きを行うため、対応不要です。

ユーザー名の打ち間違いなど、参加する見込みがないときは次の3つを行ってください。
1. 申込者に連絡を取り、正しいユーザー名を確かめる
2. 一般向けチャンネルで申込者をメンションし、ロールを付ける
3. スプレッドシートの「採択discord送信」と「ロール付与」に現在時刻を記入する

3を飛ばすと、申込者が後から参加したときに同じ連絡がもう一度届きます。
```

## D7 処理に失敗したとき

送信条件 `{{失敗した処理}}` に挙げたいずれかで止まったとき。
D6 にあたる場合は D6 だけを投稿する。

```
⚠️ 処理に失敗しました

受付番号                 {{受付番号}}
失敗した処理             {{失敗した処理}}
エラー内容               {{エラー内容}}
元の申し込み投稿         {{元投稿リンク}}

{{対応}}
```

`{{対応}}` は `{{失敗した処理}}` で決まる。下の4つに当たらなければ既定の文を出す。

| `{{失敗した処理}}` | `{{対応}}` |
|---|---|
| 既定 | 対応不要です。次の回に自動でやり直します。同じ知らせが30分以上続くときは、スプレッドシートのその行を確認してください。 |
| discord自動投稿 | 対応不要です。次の回に自動でやり直します。同じ申し込みがもう一度投稿されるので、承認のリアクションは新しいほうに付けてください。 |
| 採択discord送信の取り消し | 一般向けチャンネルを確認してください。採択を知らせる投稿が出ていなければ、スプレッドシートの「採択discord送信」列を空にしてください。次の回にやり直します。投稿が出ていれば、追加の対応は不要です。 |
| 採択投稿の記録 | 一般向けチャンネルへの投稿は届いています。追加の連絡は不要です。その投稿を右クリックして「メッセージIDをコピー」し、スプレッドシートの「採択投稿ID」列に貼ってください。記入しないと、申込者が 🆗 を押しても記録されません。 |
| ユーザー未特定の記録 | スタッフ専用チャンネルへの知らせは出ています。スプレッドシートの「ユーザー未特定通知」列に現在時刻を記入してください。記入しないと、同じ知らせがもう一度出ます。 |

## D8 スタッフに確認してほしいとき

送信条件 処理は止まっているが、エラーではないとき。

```
📌 確認をお願いします

受付番号                 {{受付番号}}
何が起きたか             {{知らせの名前}}
元の申し込み投稿         {{元投稿リンク}}

{{説明}}
```

`{{説明}}` は `{{知らせの名前}}` ごとに決まっている。

| `{{知らせの名前}}` | `{{説明}}` |
|---|---|
| 申込投稿が見つかりません | スタッフ専用チャンネルの投稿が見つかりません。消された可能性があります。承認のリアクションを数えられないので、この申し込みは止まっています。スプレッドシートの「申込投稿ID」と「discord自動投稿」を空にすると、次の回に投稿し直します。 |
| DiscordユーザーIDが読めません | 「DiscordユーザーID」列に、半角数字以外の文字が入っています。手で書き足したときの打ち間違いか、数値として丸められた値です。そのまま使うと別人にロールが付くので止めました。この列と「採択discord送信」「採択投稿ID」を空にすると、次の回に申込者を探すところからやり直します。 |

どちらもコンテナが動いている間は1件につき1回だけ投稿する。
コンテナを入れ直すともう一度出る。

# この仕組みが扱わないこと

次の4つは自動では行わない。スタッフが手で対応する。

- 不採択の連絡。承認の絵文字が2つに届かなかった申し込みには、何も自動送信されない
- 企業スポンサーの採否連絡。スポンサー申込には承認の仕組みがない。M3の受付メールのあとは担当者が手で連絡する
- ロゴ・スライドの受け取りと催促。Discordの `#community参加` などで案内する
- 当日の案内、タイムテーブル、レギュレーションの周知。すべてDiscordで行う
